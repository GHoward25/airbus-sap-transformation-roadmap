4.6C Direct-to-Greenfield S/4HANA

Leap legacy platform → native S/4HANA. Skip the ECC6 waypoint. High risk, high reward.

Why This Approach Matters for Airbus
A&D manufacturing demands regulatory rigour (Spec2k), configuration precision (ECO/BOM), and supply-chain orchestration. Both workstreams must preserve compliance whilst gaining S/4HANA agility.

Phase 3: Integration & Legacy Decommissioning

Weeks 6–10: Rationalize Interfaces & Data Migration

Legacy System Decommissioning Roadmap

  • Every 4.6C interface (supplier portals, MES, quality management, cost accounting) must re-point to S/4HANA or be decommissioned
  • Prioritise: What's Day 1 critical? What can run parallel 6–12 months?
  • A&D Risk: Supplier notification, quality certs, deviation escalation—cannot tolerate extended parallel running

Data Migration Strategy

4.6C → Greenfield has zero legacy data model continuity.

  • Migrate: Open POs, active BOMs, supplier master, quality certifications
  • Archive: Historical transaction detail, redundant cost centre data
  • Tools: LSMW or Fiori migration cockpit for A&D-relevant masters (Materials, BOM, Routing, Quality Plans)

Spec2k Risk Assessment: 4.6C → Greenfield

🔴 High Risk
QM Module Rework: Custom inspection lot logic may not map to S/4HANA 2025 quality profiles. Supplier cert generation could break.
🟡 Medium Risk
ECO / Configuration Management: Multi-level BOM versioning, effectivity dating. Native S/4HANA ECM may not support all A&D nuances.
🟡 Medium Risk
Deviation Workflows: 8D reports, supplier corrective action. Legacy SAP Workflow may need refactor to Fiori-native or BPM.
🟢 Lower Risk
Material Master / Purchase Info: Standard SAP tables. Migrate via LSMW; validate Spec2k attributes post-cutover.

Mitigation: Create "Business Criticality Heat Map" early. Document every process where greenfield simplifications might break A&D compliance. This is your risk register for executive governance.

P11 2025 Upgrade: A&D Compatibility Checks

1. Spec2k Compliance Encoding

If via QM module: inspection plan format tightens. Can cert generation still produce Spec2k-compliant documents? If via Material Attributes: INFO records (EKPO) simplified; legacy fields must migrate to purchase agreements.

2. ECM / Configuration Management

S/4HANA 2025 ECM is optional. Does Airbus run custom Z-ECO logic? Native ECM may not support multi-level BOM version cascading, date-based effectivity.

3. Supplier Quality & Deviation

2025 QM Deviation is tighter. A&D 8D reports, supplier corrective action workflows—do they survive? External quality portals for supplier submission—still supported?

4. Costing & MTO/ETO

A&D is highly MTO/ETO (low-volume, high-complexity). 2025 simplified costing. Can job costing & project cost accounting migrate cleanly?

5. Integration (PI/XI → Cloud)

If P11 runs SAP PI for supplier exchange (ASN, quality certs): can Spec2k XML/EDI transmit natively via Integration Suite? Or does custom mapping logic need refactoring?

P11 2025: Pre-Upgrade Audit Roadmap

Three Parallel Work Streams

🧪 Sandbox Testing
Test QM, MRO, ECM, Costing workflows on 2025 sandbox. Identify breakages early. Document refactoring scope.
🔄 Integration Readiness
Agree on Cloud Integration migration plan. Test Spec2k EDI / XML transmission natively. Confirm supplier interface continuity pre-upgrade.
📋 Custom Code Inventory
Classify all Z-objects: "migrate to S/4HANA native," "refactor," or "deprecate." Remove custom indexes on Z-tables before upgrade.

Timeline: Complete audit 8–12 weeks pre-upgrade. Allows 4–6-week remediation window for high-risk custom code refactoring.
